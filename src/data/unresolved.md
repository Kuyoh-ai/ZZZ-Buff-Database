# 未収録・要確認のバフ一覧

数値が確認できなかった、または現在のデータ構造で表現できないため収録していない効果。参照元は各キャラの JSON と同じサイト(game8 / gamewith / wikiwiki / mintparm)。

## 構造上表現できないため未収録(共通パターン)

- **ステータス依存の変換式**(例: 「最大HP 1Pt ごとに透徹力 +0.1」「異常掌握 100 超過分 ×1.6 を異常マスタリーに」「衝撃力 170 超過分 10Pt ごとに +0.25%」): 固定値ではないため未収録。一部は上限値を base として収録し note に式を記載
- **スキル倍率の変化**(「〜のダメージ倍率 +X%」「攻撃力の Y% 分の追加ダメージ」): バフ/デバフのステータス変化ではないため対象外
- **シールド量・被ダメージ軽減・敵の与ダメージダウン**: 対応する stat なし(ben M1、sunna M6、yidhari 追加能力、seth コアなど)
- **エネルギー獲得効率(%)**: energy_regen(自動回復)とは別概念のため未収録(grace M4 など)
- **特定異常種限定のダメージ上昇**(風化・乱流・感電ダメージなど): anomaly_dmg_pct で代用したものと未収録のものが混在(velina 追加能力/M2、grace 追加能力は代用)
- **時間延長系**(バフ継続 +8s、ブレイク継続 +3s): stat なし
- **OR 条件の編成条件**(同属性 または 同陣営): condition ではなく note に記載。アタッカー強調には反映されない

## 系統的な注意点

- **コアスキルのレベル依存値**: 原則コアスキル最大レベル時の値を base にしているが、一部ファイル(anby, billy, nekomata, nicole, trigger, astra, evelyn)は Lv.1 相当の値を採用し note に上限を記載している。統一する場合はこれらを最大値に更新する
- **音動機の中間段階(P2〜P4)**: 多くのキャラで P1/P5 からの等差補間(note に明記)。公式値と若干異なる可能性がある
- HoYoWiki は JS 描画のためほとんど直接参照できず、game8 / gamewith / wikiwiki / mintparm を主参照にしている
