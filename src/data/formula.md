# ダメージ計算式と初期値の根拠(ダメージ影響力比較機能)

調査日: 2026-10-19(Ver.3.2 時点)。本機能は「基準状態(アタッカー + 敵 + 固定バフ)の期待ダメージ」と「比較対象キャラのバフ/デバフを加えた期待ダメージ」の比を出す。スキル倍率・敵 HP・距離減衰などアタッカー固有で分母分子が同じ項は省く。

参照元の優先順位は README と同じ(HoYoWiki → wikiwiki → 英語コミュニティ)。wikiwiki の各ページは Playwright で原文を直接取得して確認した。

## 1. 通常ダメージ(強攻・撃破・支援・防護、異常キャラの直接攻撃)

```
ダメージ = 倍率 × 攻撃力 × 与ダメ枠 × 会心期待値 × 防御枠 × 耐性枠 × 被ダメ枠 × ブレイク枠
```

| 項 | 式 | 出典 |
|---|---|---|
| 攻撃力 | `((基礎攻撃力 + 音動機基礎攻撃力) × (1 + 攻撃力%_常時) + 固定攻撃力_常時) × (1 + 攻撃力%_戦闘内) + 固定攻撃力_戦闘内` | [wikiwiki ダメージ計算式](https://wikiwiki.jp/zenless/ダメージ計算式) |
| 与ダメ枠 | `1 + Σ(与ダメ% + 属性ダメ% + スキル種別ダメ%)`(1 つの加算枠) | 同上、[巴哈姆特の解析](https://forum.gamer.com.tw/C.php?bsn=74860&snA=6498) |
| 会心期待値 | `1 + min(会心率, 100%) × 会心ダメージ` | wikiwiki ダメージ計算式 |
| 防御枠 | `K / (K + 実効防御)`、`K(Lv60) = 794`、`実効防御 = max(0, 敵防御 × (1 − 防御ダウン% − 防御無視%) × (1 − 貫通率) − 貫通値)` | 同上 |
| 耐性枠 | `1 − 敵属性耐性% + 耐性ダウン% + 耐性無視%`(加算。弱点 −20% → 1.2、耐性 +20% → 0.8) | 同上 |
| 被ダメ枠 | `1 + Σ敵被ダメージ増加% − 軽減%`(与ダメ枠とは独立。ミアズマシールドのダメージカット 25% もここ) | 巴哈姆特(wikiwiki は「現状そのデバフは無い」と古い記述) |
| ブレイク枠 | ブレイク中 `弱体倍率`(標準 150%、弱体倍率+% は加算: 150 + 35 = 185%)。非ブレイク時 1.0 | wikiwiki ダメージ計算式 |

- 「常時」レイヤー = ディスク・音動機上級ステータス・コアスキル強化・ディスク 2 セット効果。「戦闘内」レイヤー = 本 DB に収録されたバフ(攻撃力% / 固定攻撃力、例: アストラの +1200 は戦闘内固定)。2 層は乗算の関係にある(wikiwiki)。
- コアスキル強化の「基礎攻撃力 +75」は基礎攻撃力に含める(wikiwiki)。
- レベル差補正は存在しない。敵の防御力は Lv60 以降上昇しない。
- 攻撃側レベル係数 K: Lv1 50 / 10 94 / 20 172 / 30 281 / 40 421 / 50 592 / 55 689 / 59 772 / **60 794**(wikiwiki ダメージ計算式)。

## 2. 命破(透徹ダメージ)

```
ダメージ = 倍率 × 透徹力 × 与ダメ枠 × 会心期待値 × 耐性枠 × 被ダメ枠 × ブレイク枠 × (1 + 透徹ダメージ%)
透徹力 = 0.3 × 攻撃力(戦闘内) + 0.1 × 最大 HP + 固定透徹力
```

- 防御枠なし(貫通率 / 貫通値 / 敵防御ダウンは無効)。[wikiwiki エージェント/命破](https://wikiwiki.jp/zenless/エージェント/命破)、[wikiwiki 儀玄](https://wikiwiki.jp/zenless/儀玄)
- 透徹ダメージ% は与ダメ枠とは別枠乗算(wikiwiki 儀玄)。
- 係数 0.3 / 0.1 は HoYoWiki の Lv60 透徹力で検算済み: 儀玄 0.3×872 + 0.1×7953 = 1056.9 → 表示 1056、真斗 976.4 → 976、イドリー / 盤岳 / スターライト・ビリー 1084.9 → 1084(端数切り捨て)。命破 5 体すべて一致するため全員共通とみなす。
- 透徹力% バフ(`sheer_force_pct`)は透徹力全体に乗算、固定(`sheer_force_flat`)は加算とする。
- **二重計上の注意**: `agent_stats.json` の `base.sheer_force` は既に 0.3×基礎攻撃力 + 0.1×基礎 HP を含んだ表示値なので参考値扱いとし、計算機は攻撃力(戦闘内)と最大 HP から透徹力を導出する(`base.sheer_force` を加算しない)。

## 3. 鋭御(鋭撃ダメージ、現状クラレッタのみ)

```
ダメージ = 倍率 × 自身の防御力 × 与ダメ枠 × 鋭御会心 × 防御枠 × 耐性枠 × 被ダメ枠 × ブレイク枠 × (1 + 鋭撃ダメージ%)
鋭御会心 = 1 + CR × L                         (CR ≤ 100%)
         = (1 + L) × (1 + (CR − 1) × L)       (100% < CR ≤ 200%、超過分は無効)
L = 暴傷ダメージ(基礎 150%) + 暴傷ダメージバフ
```

- 攻撃力・HP・会心ダメージはダメージに入らない。会心率バフは有効(上限 200%)。[wikiwiki エージェント/鋭御](https://wikiwiki.jp/zenless/エージェント/鋭御)、[wikiwiki クラレッタ](https://wikiwiki.jp/zenless/クラレッタ)、巴哈姆特
- 鋭撃ダメージ% は与ダメ枠とは別枠乗算([wikiwiki クラレッタ](https://wikiwiki.jp/zenless/クラレッタ)「鋭撃ダメージバフとは、命破にとっての透徹ダメージのように別枠乗算のバフ」)。2026-10-19 に鋭御専用 stat `sharp_dmg_pct`(鋭撃ダメージ)を新設し、クラレッタの音動機「深紅の渇望」の電気属性鋭撃ダメージ +10〜16% と危局/激変バフの鋭撃ダメージを収録(2026-09-24 の「stat を新設しない」方針を計算機の必要から変更)。
- 暴傷の仕組み(wikiwiki クラレッタ原文): 「会心発生時、鋭撃ダメージには会心ダメージボーナスの代わりに暴傷ダメージボーナスが適用される。会心率が 100% を超えている状態で会心が発生した場合、超過分の会心率に基づき暴傷判定をもう一度行い、『暴傷』が発生すれば暴傷ダメージボーナスが追加で 1 回適用される」「この会心判定は 2 回までとなっているので、200% を超えた分の会心率は効果がない」。追加適用は乗算(2.5 × 2.5 = 6.25、巴哈姆特)として実装。暴傷ダメージ% のバフ: クラレッタ追加能力「残鋭」+25(鋭御全員)、ロクシー コア +20、クレタ ポテンシャル T2〜T6 +4〜12。
- クラレッタ固有: 開幕会心ダメージ 1% ごとに開幕会心率 +0.35%(ディスクの会心ダメージが会心率に変換される)。これはクラレッタのコアパッシブであり鋭御共通の規則ではない。**`agent_stats.json` の `base.crit_rate` 22.5% は基礎会心ダメージ 50% の変換分(5 + 0.35×50)を既に含む**ため、変換はディスク・音動機・コア由来の会心ダメージにのみ適用する(基礎 50% 分を再変換しない)。
- 敵防御枠は適用される(巴哈姆特のみの記述。中確信)。

## 4. 属性異常・混沌

```
異常ダメージ = 異常基礎% × 攻撃力 × (異常マスタリー / 100) × Lv係数 × 与ダメ枠 × 異常ダメ枠 × 防御枠 × 耐性枠 × 被ダメ枠 × ブレイク枠
Lv係数 = 1 + (Lv − 1) / 59 (Lv60 = 2.0)
異常ダメ枠 = 1 + Σ(属性異常ダメージ% + 敵被異常ダメージ%)、混沌は (1 + 混沌ダメージ%)
```

- 会心しない(ジェーン等の固有例外を除く)。異常掌握は蓄積値のみに関わりダメージには入らない。[wikiwiki 状態異常](https://wikiwiki.jp/zenless/状態異常)
- 異常ダメージ% は与ダメ枠とは別枠乗算(wikiwiki 状態異常)。混沌ダメージ% と異常ダメージ% を同枠とするか別枠とするかは解析者間で見解が割れる(巴哈姆特は別枠)。本機能では別枠。
- 蓄積側: `蓄積値 = 基礎蓄積 × (異常掌握 / 100) × (1 + 蓄積効率%) × (1 − 敵蓄積耐性%)`。発動回数はこれに比例するため、異常キャラの「時間あたりダメージ」の近似として蓄積側の倍率も乗じる(オプション、既定 ON を提案)。
- 異常基礎%(参考、倍率は比率計算で打ち消される): 強撃 713% / 砕氷 500% / 風化 1250% / 燃焼 50%/0.5s / 感電 125%/s / 侵蝕 62.5%/0.5s。

## 6. エージェント初期ステータス(`agent_stats.json`)

HoYoWiki の公開 API から `scripts/fetch-agent-stats.py` で生成。各レコードに `sourceUrl`。

- `base`: Lv60 の HP / 攻撃力 / 防御力と、レベルで変化しない衝撃力 / 会心率 5% / 会心ダメージ 50% / 異常掌握 / 異常マスタリー / 貫通率 / エネルギー自動回復(命破は透徹力、鋭御は暴傷ダメージ 150% と会心率 22.5%)
- `core`: コアスキル強化ステータスの A〜F 合計(例: 基礎攻撃力 +75、会心率 +14.4%、異常マスタリー +90、儀玄は HP +420)
- `wengine`: モチーフ音動機の Lv60 基礎攻撃力(クラレッタは基礎防御力)と上級ステータス(key と値)。HoYoWiki の表記揺れは `advLabelNote` に記録

戦闘外の攻撃力 = `(base.atk + core.atk + wengine.baseValue) × (1 + 攻撃力%_常時) + 固定攻撃力_常時`。

## 8. 敵プリセット(`enemies.json`)

- 敵防御 = Lv1 基礎防御 × K(min(Lv, 60)) / 50。Lv60 以上は ×15.88。基礎 60 のボス → Lv70 で **952.8**。始まりの主 476、ワンダリングハンター 1588(wikiwiki 危局強襲戦/敵一覧)
- 危局強襲戦のボスは Lv70(英語攻略記事 3 件。wikiwiki に明記なし)。逆境モードのレベルは未確認
- 弱点 / 耐性は wikiwiki のアイコン表示のみで、個別 % は非公開。弱点 −20% / 耐性 +20% を仮定(通説、一部 +40% の敵あり)
- 弱体倍率は標準 150%。個別値が確認できたのはミアズマ・フィーンド 125% のみ
- ミアズマシールド展開中: 防御 +80%(防御ダウンと同枠)・ダメージカット 25%・ブレイク不可。始まりの主は +10% / 50%、ハイヨト・ワンダリングハンターは +100% / 25%(wikiwiki ダメージ計算式)

## 9. 危局強襲戦バフ / 激変ノードバフ

Ver.3.0〜3.2 の危局 9 期と激変 3 期を確認(wikiwiki 危局強襲戦 / 過去データ4・5 / 式輿防衛戦)。出現した種類: 攻撃力% (+5〜25) / 会心ダメージ (+15〜50) / 与ダメ% / スキル種別ダメ% (+20〜30) / 属性ダメ% (+15〜40) / 敵防御ダウン・防御無視 (10〜25) / 耐性ダウン・耐性無視 (10〜30) / 異常マスタリー (+10〜70) / 貫通率 (+5〜10) / 弱体倍率 (+20〜40) / 透徹ダメ% / 鋭撃ダメ% / 状態異常ダメ% / 混沌ダメ% / 蓄積効率 / ブレイク値。会心率とシールド系は 0 件。

既存の stat キーで表現できないもの: 鋭撃ダメージ%(stat なし)、ブレイク復帰速度、ミアズマシールド減少値、エネルギー / デシベル。計算 UI では「固定バフ」として `stat キー + 値` の自由入力で表現し、現行期のプリセットを数個用意する。

## 10. ユニットテスト用の手計算 fixture

攻撃力(戦闘内) 3000 / 会心率 70% / 会心ダメージ 150% / 与ダメ +50% / 敵防御 952.8 / 貫通率 20% / 防御ダウン 0 / 弱点(−20%) / ブレイク中 150% / 被ダメ 0 / 倍率 100%:

```
実効防御 = 952.8 × (1 − 0) × (1 − 0.20) − 0 = 762.24
防御枠   = 794 / (794 + 762.24) = 0.510204
期待値   = 3000 × 1.5 × (1 + 0.7 × 1.5) × 0.510204 × 1.2 × 1.5 = 8471.94
```

命破(同条件、最大 HP 15000、透徹ダメ 0): 透徹力 = 0.3 × 3000 + 0.1 × 15000 = 2400 → 2400 × 1.5 × 2.05 × 1.2 × 1.5 = 13284.0(防御枠なし)。
鋭御(同条件、防御力 1000、会心率 130%、暴傷 150%): 会心 = 2.5 × (1 + 0.3 × 1.5) = 3.625 → 1000 × 1.5 × 3.625 × 0.510204 × 1.2 × 1.5 = 4993.62。

## 11. 確信度と未解決

- 高: 通常ダメージの構造、K = 794、敵防御 952.8 / 1590、耐性の加算、弱体倍率の加算、透徹力の係数、ディスク数値
- 中: 鋭御の式(wikiwiki + 巴哈姆特)、被ダメ枠の独立性(巴哈姆特)、敵レベル 70(英語記事)、ボス個別の弱体倍率(ほぼ 150% と推定)

## 12. 実装メモ(2026-10-19、`src/lib/damage.ts` / `src/lib/compare.ts`)

- **狂咲**: 状態異常中の敵への特定の命中で「元の状態異常ダメージの X%」を追加発生させる仕組み(グレース・ビビアン・バーニス・プロメイア・ヴェリナ等。[wikiwiki ビビアン](https://wikiwiki.jp/zenless/ビビアン)「追加で状態異常ダメージを 1 回与える。ダメージ量は異常マスタリー 10Pt につき元の状態異常ダメージの V%」)。属性ごとの固有倍率(感電 280% / 燃焼 700% / 強撃 50% / 砕氷 70% / 侵蝕 560% / 風化 28%)は各異常の基礎値を揃える係数で比率計算では打ち消される。計算は 状態異常ダメージの式 × (1 + 狂咲ダメージ%)。狂咲ダメージ% は stat `abloom_dmg_pct` を新設(プロメイアの 2 件を再キー)。蓄積側(発動頻度)は狂咲には乗せない(発動回数はアタッカーの命中回数で決まる)
- **異常会心**: 次バージョンで状態異常に会心が発生する予定のため、`DamageOptions.anomalyCrit`(UI の「状態異常に会心を適用」)で会心期待値を乗じられる。既定 OFF
- **追加能力の判定**: 基準編成(アタッカー + 3 枠目)と候補編成(+ 比較対象)それぞれで、同席メンバーの誰かが条件を満たせば ON(既存一覧の 2 人基準と同じく不在の 3 人目は当てにしない)。候補がアタッカー/3 枠目の追加能力を発動させる場合、その分も候補の比率に含め、行に「○○の追加能力を発動」と表示する
- **ライカンのデータ修正**: 「氷属性以外の被ダメージ増加」(`lycaon_core_other_element_dmg_taken`)に受け手の属性条件(氷以外)を追加。従来は氷アタッカーにも乗っていた
- **弱体倍率の上限**: ブレイク枠は `min(上限, 基礎弱体倍率 + Σ弱体倍率バフ)`。上限は敵プリセットの `stunMultiplierMax`(任意)または UI の「弱体倍率の上限」欄で指定し、3 枠目・固定バフ・比較対象の分を合計してからカットする(3 枠目で上限に達していれば候補の弱体倍率バフは ×1.00)。上限値の一次情報は未確認のためプリセットには入れていない(UI で指定)
- **既知の限界**: 敵のギミック(重ねがけの被会心ダメ増減など)は note のみ。ディスク 4 セット効果は含めない

## 13. 監査後の追加仕様(2026-10-19、ユーザー回答に基づく)

- **受け手の表現**: `target` に `active`(出場中のメンバー。出し手が控えの時に付与、自身以外)と `bench`(控えのメンバー。アタッカーには乗らない)を追加。「自身と出場メンバー」(アストラ)、「次のメンバーに引き継ぐ」(蒼角)、「ノルムーと対応メンバー」は self + next_swap_in の 2 エントリ
- **modes**: バフに `modes`(direct / anomaly / abloom / disorder)を付けると該当モードでのみ計算に入る。狂咲限定の耐性/防御無視(ビビアン M2、プロメイア追加能力)、強撃(物理異常)限定のジェーンの会心・防御無視に使用
- **状態異常の固有会心**: `anomaly_crit_rate` / `anomaly_crit_dmg`。状態異常モードでは常に適用し、「状態異常に会心を適用」トグル ON のときは通常の会心率/会心ダメージと合算する(Ver.3.3 の異常会心と統合する前提)
- **混沌ダメージ倍率**: `disorder_multiplier_pct` は混沌の基礎倍率 450% への加算として `(450 + X) / 450` を混沌モードでのみ乗じる(残秒数依存の加算分は無視した近似)
- **単位の分離**: `energy_gain_eff_pct`(エネルギー獲得効率%)、`energy_regen_pct`(自動回復%)、`decibel_gain_eff_pct`(デシベル獲得効率%)を新設し、固定 Pt の stat と分けた(計算には影響しない)
- **スキル限定の与ダメ**: 「〇〇スキルの与ダメージ+X%」は self の `basic/dash/ex/chain/ult/assist_dmg_pct` として収録し、攻撃種別セレクタで反映する
- **A 級モチーフ音動機**: HoYoWiki の「モチーフ音動機」欄に従い 11 体分を収録(ベンは被ダメ軽減/追加ダメージのみで対象外)。`characters.json` の `wengine` 名も設定
- **重傷モード(鋭御、2026-10-19)**: 「重傷」は「残痕」を消費して発生する鋭撃ダメージの単発ヒット(wikiwiki クラレッタ: スキル Lv12 で倍率約 1600%、M1 で本来の 130%)。式は鋭御の直接攻撃と同じ(防御力基準 × 与ダメ枠 × 暴傷の 2 段会心 × 防御枠 × 耐性 × 被ダメ × ブレイク × (1 + 鋭撃ダメ%))に `(1 + 重傷ダメージ倍率%)`(stat `grievous_multiplier_pct`、`modes: ["grievous"]`)を別枠で乗じる。攻撃種別限定バフ(通常/強化特殊/… ダメ%)は含めない。暴傷ダメージバフは会心率 100% 超過時に 1 段目・2 段目の両方に乗るため、会心率 200% で (1+L+ΔL)² / (1+L)² の効果になる(例: L 150% に +25% で ×1.21)
- **異常マスタリー比例の効果(2026-10-21)**: 「異常マスタリー 1Pt につき〜」型の効果は固定の上限値ではなく、バフの `scale`(per / from / cap)で出し手のパネル値(+ 固定バフ)から実値を計算する。ジェーン(M1 与ダメ +0.1%/Pt 上限 30、コア 攻撃力 +2/Pt(120 超過分)上限 600、コア 強撃会心率 +0.16%/Pt 上限なし)、バーニス(エンバー与ダメ +1%/10Pt 上限 30)、プロメイア(異常掌握 150 超過分 × 1.5 → 異常マスタリー、× 0.35% → チーム狂咲ダメ)、柚葉(異常掌握 100 超過分 × 0.2% 上限 20)。これにより異常マスタリーを配るバフ(セス +100 等)の効果が、これらの派生効果の分だけ大きくなる
- **ビビアンの狂咲**: 「異常マスタリー 10Pt につき元の状態異常ダメージの X%」(HoYoWiki)なので狂咲ダメージは AP の 2 乗に比例。`characters.json` の `abloomApScaling` で狂咲モードの AP/100 をもう一度乗じる
- **乱流換算(2026-10-21、ヴェリナ)**: 乱流持ち(`characters.json` の `turbulence`)がチームにいる状態異常モードでは、アタッカーの状態異常(熱傷/感電/侵蝕の継続ダメージ等)は発生せず、代わりに乱流持ち自身のステータスで乱流ダメージが発生する(wikiwiki 状態異常: 「乱流を発動しても風化は終了せず、継続ダメージは発生しない」、HoYoWiki ヴェリナ: 「ヴェリナが与える風化と乱流のダメージ」)。比率 = ヴェリナの状態異常ダメージ(自身の攻撃力・異常マスタリー・与ダメ/異常ダメ枠、蓄積側なし) × 乱流倍率(物理 1588 / 炎 1900 / 氷 1825 / 電気 1900 / エーテル 1900) × アタッカーの蓄積倍率(発動頻度) ÷ (アタッカーの状態異常ダメージ × 元の異常の総倍率(強撃 713 / 熱傷 1000 / 砕氷 500 / 感電 1250 / 侵蝕 1250))。風/流明/玄墨のアタッカー、直接攻撃・狂咲・混沌モードでは換算しない。ヴェリナ側のバフはヴェリナを受け手として集計する(属性付きバフはヴェリナの属性=風で判定する近似)。3 枠目がヴェリナなら基準も乱流換算
